# 初めてのSpresense Blocks

このページは、Spresense Blocksを初めて使う生徒・先生向けのチュートリアルです。
インストール方法は [README.md](../README.md) を参照してください。ここでは
「起動できた後、最初に何をすればよいか」を説明します。

## 1. 画面の見かた

アプリを起動すると、上のツールバーと、その下の3つのエリアが見えます。

- **左側(ツールボックス)**: 「制御」「動作」「センシング」などのカテゴリをクリックすると、
  使えるブロックの一覧(フライアウト)が出ます。ここからブロックを右側の作業エリアに
  ドラッグ&ドロップします。
- **中央(作業エリア)**: ブロックを組み立てる場所です。最初から「ずっと」というオレンジの
  ブロックが1つ置いてあります。SPRESENSEの動きは、このブロックの中に積み木のように
  ブロックを入れて作ります。
- **右側(メッセージ / C++コード)**: 「メッセージ」タブには、書き込みの進み具合やエラーが
  表示されます。一番上の帯の色で、今の状態(青: 書き込み中、緑: 完了、赤: エラー)がわかります。
  「C++コード」タブでは、組んだブロックから作られたプログラム(C++)を見られます。

ツールバーのボタン(左から順に):

| ボタン | 働き |
|---|---|
| 開く / 保存 | プログラムを`.sprsb`ファイルとして保存・読込します |
| (ポート選択) | SPRESENSEをつないでいるUSBポートを選びます。つなぐと自動で選ばれます。左の丸が緑ならSPRESENSEを認識できています |
| 書き込む | 組んだブロックをC++に変換(コンパイル)し、SPRESENSEに書き込みます |
| 音源コピー(♪) | 「ゆる楽器」ブロックで使う音源をSDカードに用意します(後述) |
| コード(`<>`) | 右側を「C++コード」タブに切り替えます(Ctrl+Shift+Cでも切り替えられます) |
| USBが認識されないとき(?) | ドライバーの案内ページを開きます |

画面の横幅が狭いときは、右側のボタンが絵(アイコン)だけになります。
マウスを乗せると、ボタンの説明が表示されます。

## 2. 最初のプログラム: Lチカを作ってみよう

電子工作の「Hello, World」と言われる、LEDを点滅させるプログラムを作ります。

1. ツールボックスの「動作」カテゴリを開き、「オンボードLED ◯ を ◯ にする」ブロックを
   「ずっと」の中にドラッグします。
2. ドロップダウンでLEDを選び、「点ける」を選びます。
3. ツールボックスの「制御」カテゴリから「◯ミリ秒待つ」ブロックを、さっき置いたブロックの
   **下**にくっつけます。数字は`500`のままでOKです(0.5秒待つという意味です)。
4. もう一度「オンボードLED ◯ を ◯ にする」ブロックを追加し、今度は「消す」を選びます。
5. もう一度「◯ミリ秒待つ」ブロックを追加します。

これで「LEDを点ける→0.5秒待つ→LEDを消す→0.5秒待つ」を「ずっと」繰り返すプログラムが
完成です。SPRESENSEをUSBでつないで、ポートを選んでから「書き込む」を
押してみましょう。基板上のLEDが点滅すれば成功です。

(このプログラムは [samples/01_Lチカ.sprsb](../samples/01_Lチカ.sprsb) としても
用意してあります。「開く」から開いて確認できます。)

## 3. サンプルを開いてみよう

`samples/` フォルダに、すぐ試せるサンプルプログラムを用意しています。
ツールバーの「開く」から開いて、実際にSPRESENSEに書き込んで動かしてみてください。

| ファイル | 内容 | 必要なもの |
|---|---|---|
| `01_Lチカ.sprsb` | オンボードLEDを0.5秒おきに点滅させる、一番シンプルな例 | SPRESENSE本体のみ |
| `02_明るさセンサーでLEDの明るさを変える.sprsb` | A0に明るさセンサー(CdSセル等)をつなぐと、その値に合わせてD05のLEDの明るさが変わる | 明るさセンサー、LED、抵抗 |
| `03_ゆる楽器_ボタンドラム.sprsb` | D04・D05・D06にボタンをつなぐと、それぞれ違う音程のピアノ音が鳴る「ボタン楽器」 | ボタン×3、SDカード、スピーカー(下記参照) |
| `04_傾きセンサーでLED.sprsb` | センサー拡張ボードの加速度センサーで、基板を傾けるとLED1が点灯する | センサー拡張ボード(SSCI-052580) |
| `05_繰り返しでLEDを点滅させる.sprsb` | 「3回繰り返す」を使って、LED0を3回素早く点滅させ、1秒休むことを繰り返す | SPRESENSE本体のみ |
| `06_ボタンでLEDを点ける.sprsb` | D04のボタンを押している間だけLED0が点く。「変数」と「もし〜なら」の練習 | ボタン、抵抗(下記参照) |
| `07_温度でLEDを点ける.sprsb` | 温度が28℃を超えるとLED1が点く。センサーを指で温めると変化がわかる | センサー拡張ボード(SSCI-052580) |
| `08_ゆる楽器_和音ボタン.sprsb` | D04・D05・D06のボタンで、それぞれ違う和音(ド+ミ、ファ+ラ、ソ+シ)が鳴る | ボタン×3、抵抗×3、SDカード、スピーカー |
| `09_ゆる楽器_傾き楽器.sprsb` | 基板を右(または左)に傾けると、ド(またはソ)の音が鳴る | センサー拡張ボード、SDカード、スピーカー |

サンプルは番号順に、少しずつ新しいブロックが出てきます。上から順に試すと、
ブロックの使い方を無理なく広げていけます。もちろん、気になったものから
自由に開いて大丈夫です。

### 「ゆる楽器」サンプルを鳴らすには

`03_ゆる楽器_ボタンドラム.sprsb` を実際に鳴らすには、事前にSDカードへ音源ファイルを
コピーしておく必要があります。

1. ツールバーの「音源コピー」(♪のボタン)を押します。
2. SPRESENSEからmicroSDカードを一度取り外し、PC本体やUSBカードリーダーに挿します。
3. 「探す」でドライブを検出し、「ピアノ」にチェックが入っていることを確認して
   「コピーする」を押します。
4. SDカードをSPRESENSEに戻し、スピーカーを拡張ボードのヘッドホン端子につなぎます。
5. D04・D05・D06にそれぞれボタンをつなぎ(つなぎ方は次の「ボタンのつなぎ方」を参照)、
   プログラムを書き込みます。

音が出ない場合は、SDカードのルートに `Piano` フォルダと中身のWAVファイルが
ちゃんとコピーされているか確認してください。

### ボタンのつなぎ方

「デジタルピン ◯ がONになっている」ブロックは、ピンの電圧が**高い(HIGH)**ときに
「ONになっている」と判断します。そのため、ボタンを押したときにピンへ電源の電圧が届き、
押していないときはGNDにつながっている、という回路にします。

1. ボタンの片側を、使いたいピン(例: D04)につなぎます。
2. ボタンのもう片側を、電源(拡張ボードの3.3V。お使いの基板の入出力電圧に合わせてください)につなぎます。
3. 同じピンとGNDの間に、10kΩ程度の抵抗(プルダウン抵抗)をつなぎます。

プルダウン抵抗がないと、ボタンを押していないときにピンの電圧が不安定になり、
押していないのに「ON」と判断されることがあります。反応がおかしいときは、
まず配線とこの抵抗を確認してみてください。

## 4. 次のステップ: ブロックを組み合わせてみよう

Lチカができたら、次は「繰り返し」「もし〜なら」「変数」を使ってみましょう。
ここでの手順は、`samples/` のサンプルと同じ内容です。手順どおりに組めなくても、
サンプルを開いて見比べれば大丈夫です。

### 4-1. 繰り返しブロックを使う(サンプル05)

同じ動きを何度も書くかわりに、「◯回繰り返す」ブロックにまとめられます。

1. 「制御」から「◯回繰り返す」ブロックを「ずっと」の中に入れ、回数を`3`にします。
2. 繰り返しの中に「LED0を点ける → 100ミリ秒待つ → LED0を消す → 100ミリ秒待つ」を入れます。
3. 繰り返しブロックの下に「1000ミリ秒待つ」を足します。

3回点滅して、1秒休む動きになります。

**やってみよう**: 回数や待つ時間を変えると、点滅のリズムはどう変わるでしょうか。
「3回」を「5回」に変えたり、休む時間を短くしたりして、試してみてください。

### 4-2. ボタンでLEDを点ける: 変数と「もし〜なら」(サンプル06)

「ボタンを押している間だけLEDを点ける」プログラムです。ここでは「押した」という
変数に、ボタンの状態を覚えさせます。

1. 「変数」から「変数 ◯ を ◯ にする」を使い、名前を`押した`、値を`0`にします。
2. 「もし〜なら」に「デジタルピン D04 がONになっている」を入れ、中で`押した`を`1`にします。
3. 「もし 変数押した = 1 なら LED0を点ける」を作ります。
4. 「もし 変数押した = 0 なら LED0を消す」を作ります。

毎回必ず最初に`押した`を`0`に戻すので、ボタンを離せば自然にLEDが消えます。

**やってみよう**: D04のかわりに別のピンを使ってみたり、LED0をLED1に変えたりしてみてください。
慣れてきたら、ボタンを2つにして、LEDを2つ別々に光らせることにも挑戦できます。

### 4-3. センサーの値で動かす(サンプル07・09)

センサー拡張ボードがあれば、温度や傾きに反応するプログラムも作れます。
考え方は4-2と同じで、「センサーの値を変数に入れる → 比べる → 動かす」です。

- サンプル07: 温度が`28`を超えたらLED1を点けます。部屋の温度が既に28℃を超えている場合は、
  数字を変えてみてください(部屋の温度より少し高い値にすると、指でセンサーを温めたときに
  変化がわかります)。
- サンプル09: 加速度センサーの値が`0.5`より大きい(または`-0.5`より小さい)とき、
  ちがう音を鳴らします。基板をゆっくり傾けてみてください。

**やってみよう**: 07の数字を変えて、LEDが点く温度を自分で決めてみましょう。
09の`0.5`を小さくすると、少しの傾きで音が鳴るようになります。

### 4-4. 和音を鳴らす(サンプル08)

「ゆる楽器」の「和音を鳴らす」ブロックは、2つの音を同時に鳴らします。
サンプル08では、ボタンごとに次の和音を割り当てています。

| ボタン | 和音 |
|---|---|
| D04 | ド + ミ |
| D05 | ファ + ラ |
| D06 | ソ + シ |

**やってみよう**: 好きな2音の組み合わせに変えて、聞こえ方の違いを楽しんでみてください。
音の長さを変えると、余韻の長さも変わります。

## 5. 自分のプログラムを保存する

ツールバーの「保存」を押すと、組んだブロックを`.sprsb`ファイルとして保存できます。
次回起動したときは「開く」から読み込めば、続きから編集できます。

## 困ったときは

- SPRESENSEが認識されない: ツールバー右端の「USBが認識されないとき」(?のボタン)から、
  ドライバーの案内ページを開けます。
- 「拡張センサー」や「ゆる楽器」のブロックを使ったプログラムが動かない:
  対応するハードウェア(センサー拡張ボード、SDカードの音源)が揃っているか確認してください。
  コンパイル自体は通っても、ハードウェアが無いと実際の動作は確認できません。
- その他の設計の考え方は [docs/architecture.md](./architecture.md) を、
  新しい機能を追加する方法は [docs/adding-a-block-pack.md](./adding-a-block-pack.md) を参照してください。
