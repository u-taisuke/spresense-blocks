「ゆる楽器」に新しい音色(オルガン・鉄琴・8ビット)を追加し、ブロックの入力欄をキーボードのTabキーで移れるようにしたアップデートです。

## インストール方法

`Spresense.Blocks.Setup.1.2.0.exe` をダウンロードして実行してください。管理者権限は不要です。以前のバージョンを使っている場合も、そのまま上書きでインストールできます(保存したプログラムはそのまま使えます)。

**注意**: コード署名していないため、Windows Defender SmartScreenの警告(「Windows によって PC が保護されました」)が表示されます。「詳細情報」→「実行」で進めます。

## 新しい機能

- **ゆる楽器の音色を5つに**: 「ゆる楽器を鳴らす」ブロックで、これまでのピアノ・サックスに加えて、**オルガン・鉄琴・8ビット**(昔のゲーム機風の音)を選べるようになりました。どの音色も2オクターブ(低いド〜シ)を鳴らせます
- **Tabキーで入力欄を移動**: ブロックの数字・文字の欄とドロップダウンを、Tabキーで順番に移れるようになりました(Shift+Tabで前へ)。順番は「上から下、左から右」で、最後の欄の次は最初の欄に戻ります。ブロックをクリックして選んでから Tab を押すと、そのブロックの最初の欄が開きます

## 新しい音色を使うには

新しい音色の音源は、SDカードにコピーする必要があります。アプリを更新したら、ツールバーの「音源コピー」(♪のボタン)から、もう一度SDカードにコピーしてください。SDカードに `Organ`(オルガン)・`Glock`(鉄琴)・`Chip`(8ビット)のフォルダが追加されます。

詳しくは [README](https://github.com/u-taisuke/spresense-blocks/blob/v1.2.0/README.md) と
[チュートリアル](https://github.com/u-taisuke/spresense-blocks/blob/v1.2.0/docs/tutorial.md) を参照してください。

## 既知の制限

- 新しい音色は、ピアノ・サックスと同じく倍音を合成して作った音です。開発者がまだSPRESENSEの実機のスピーカーで聞こえ方を確認できていません。
- 「ゆる楽器」のメロディ、拡張センサー(加速度・気圧・温度)のサンプルも、コンパイルは通ることを確認していますが、実機での確認はまだです。詳しくは [roadmap.md](https://github.com/u-taisuke/spresense-blocks/blob/v1.2.0/docs/roadmap.md) を参照してください。
