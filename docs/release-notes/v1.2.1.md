初めて起動したときの準備(arduino-cli と SPRESENSEのボード情報のダウンロード)が、遅い回線やプロキシのあるネットワークで終わらなかった問題を修正したアップデートです。

## インストール方法

`Spresense.Blocks.Setup.1.2.1.exe` をダウンロードして実行してください。管理者権限は不要です。以前のバージョンを使っている場合も、そのまま上書きでインストールできます(保存したプログラムはそのまま使えます)。

**注意**: コード署名していないため、Windows Defender SmartScreenの警告(「Windows によって PC が保護されました」)が表示されます。「詳細情報」→「実行」で進めます。

## 修正した問題

- **遅い回線で準備が終わらない**: 準備のダウンロード(合計約250MB)を、一定時間で打ち切っていたため、回線が遅いと正常に進んでいても途中で中断され、何度試しても終わりませんでした。遅くてもダウンロードが進んでいる限りは待ち続け、通信が止まってしまったときだけエラーにするようにしました
- **プロキシのあるネットワークでダウンロードできない**: Windows の「プロキシ設定」(自動構成スクリプトを含む)に設定されたプロキシを使うようにしました。ID・パスワードが必要なプロキシには、まだ対応していません
- **止まっているように見える**: 準備の画面に、ダウンロードした量(例: 「3.2 / 17.1 MB (18%)」)などの進み具合を表示するようにしました

すでに準備が終わっているPCでは、この更新による変化はありません。

## 学校のネットワークで使うとき

初めて起動したときだけ、次の接続先(すべて HTTPS)へのアクセスが必要です。フィルタリング等でつながらない場合は、ネットワーク管理者に許可を依頼してください。

- `github.com`
- `release-assets.githubusercontent.com`
- `downloads.arduino.cc`

詳しくは [README](https://github.com/u-taisuke/spresense-blocks/blob/v1.2.1/README.md) を参照してください。
